# HD2 Bot · 使用说明（通用版）

> 适用于任意部署实例。本文档展示的是默认指令集，具体以部署者的配置为准。

## 一、群内指令大全（`/` 前缀，无需 @）

| 指令 | 功能 | 输出 |
| --- | --- | --- |
| `/战报` | 战况速报 | 当期 MO + 战略指令 / 战略机遇 / 次要指令 + 目标星球战况 + 战区玩家分布 + 最新资讯 |
| `/重要指令` | MO 独立通知 | 当期 NEW MAJOR ORDER 官方中文、独立横幅、三类特别指令、任务状态、倒计时与定位链接 |
| `/dss` | DSS 状态 | 停靠星球（中文名）+ 实际生效的战略行动（从停靠星球页面抓取）+ 投票倒计时 |
| `/战役` | 活动战役档案 | 档案头图 + 全部阶段报告墙：简报、战报、结果、阶段奖励和独立阶段头图 |
| `/分析` | LLM 战局分析 | DeepSeek 生成：威胁概述 / 关键目标 / 行动建议 / 风险提示 |
| `/api` | API 变动监测 | 当前会话自动订阅；每分钟检查 Issue #60，真实内容变化时主动推送 |
| `/查表` | 变量对照表 | 分类列表（终结族变种/特殊个体/机器人军团/特殊单位/辅助军团/友军火力/光能族宗派/深域惧像/DSS战略行动/入侵等级/入侵战役/环境条件） |
| `/查表 <参数名>` | 参数详情 | 如 `/查表 孢裂变种`、`/查表 spore`：译文+原文+分类+描述（中英文均可） |
| `/查表 <分类名>` | 分类子条目 | 如 `/查表 深域惧像`、`/查表 DSS战略行动`、`/查表 COSMIC HORROR` |
| `/查表 星区` | 星区列表 | 星图对照表全部星区 |
| `/查表 星区 <星区名>` | 星区星球 | 如 `/查表 星区 巴纳德`：该星区所有星球（中文（英文）格式） |
| `/roll` `/随机战备` | 随机战备 | 全类型战备池随机抽 4 个，同类型≥3 附带评价 |
| `/btk <武器> <敌人> <部位>` | 伤害/卡阈值测试 | HUD 图片卡：BTK、TTK、打残/致死与阈值差；支持距离、角度、破片、波及参数 |
| `/btk 卡阈值 <武器>` | 阈值组合扫描 | 阈值矩阵卡：列出接近少一发击杀的敌人致死部位 |
| `/btk DOT-... <敌人>` | DoT 伤害测试 | 持续伤害无需部位，输出每跳伤害、触发次数、持续时间和元素倍率 |
| `/btk 武器` / `/btk 敌人` | 测试资料菜单 | 查询 149 件武器、118 种敌人及部位数据 |
| `/拆毁值 <来源>` | 常见目标对照 | 同时展示最佳直击/爆炸路线，并对照广播塔、虫穴、构筑者等常见目标 |
| `/拆毁值 <来源> <目标>` | 拆毁值对照 | 展示指定目标的直击/爆炸 DF、门槛、最大拆毁距离 |
| `/拆毁值 直击 / 爆炸物 / 常见目标 / 建筑` | 拆毁资料菜单 | 查询直击来源、爆炸曲线、常见目标和完整建筑需求 |
| `/<变种名>` | 变种扫描 | 扫描战役星球行动变量，输出存在该变种的星球（孢裂/掠食/爆裂变种、蟑龙、霸王虫、炽灼部队、生化人、喷气旅、无脑群氓、占领者等） |
| `/查询 <星球名>` | 星球信息 | 如 `/查询 奥密克戎`、`/奥密克戎信息`：抵抗度/解放状态、行动变量（部队/环境/变种/DSS）、入侵等级、入侵战役、战略目标、POI |

**查询规则**：
- 参数/分类/星区名支持中英文、忽略大小写和空格（`DSS战略行动` = `DSS 战略行动` = `TACTICAL ACTION`）
- 查无结果提示：「未查询到该参数，请输入「/查表」或「/查表 星系」查看参数。」
- 星区译名只认对照表已填中文，未填保持英文（不自行音译）
- 战略机遇读取 `strategic.active/status/dispatch_id`；战略指令和次要指令分别读取对应 assignment，不再把三类公告混在一起
- 没有官方独立 MINOR ORDER 时，界面会明确标记“重要指令附加目标”，不会把 MO 的附加守持目标当成独立次要指令
- 新 MO 首次被战况命令发现时，按“平台 + 用户”自动通知一次；`/战报`、`/重要指令` 始终显示当期内容

## 二、Web 控制台（默认 http://127.0.0.1:8630）

| 卡片 | 功能 |
| --- | --- |
| 🛠️ 一键启动部署 | 一键启动（AstrBot+SnowLuma+验证连接）｜协议端WebUI｜重启SnowLuma（QQ掉线重新注入）｜重启WebUI（自愈）｜状态 |
| 🚀 一键发送 | 点按钮直接生成并推送到群：战报 / DSS / 战役 / 分析 / 查表 / Roll / 使用说明 |
| 📊 推送战报 / 🎲 随机战备 / 🪐 星球信息 / 🧬 变种查询 / 📢 自定义消息 | 各类内容生成并推送 |
| 🧪 查询推送/响应测试 | 测试并推送（注入拿回复→发群）｜仅测试（不发群）；输入框支持任意 `/` 指令 |

> 说明：「一键发送/推送」走 OneBot HTTP API（协议端 SnowLuma，3000 端口）真实发到群；「仅测试」走 WS 注入（不污染群聊，直接看机器人回复）。

## 三、配置

所有本机信息集中在 `config.json`（复制自 `config.example.json`，已被 .gitignore 排除）：
- `bot.self_id` — 机器人 QQ 号、`bot.groups` — 白名单群、`bot.default_group` — 默认推送群
- `snowluma.access_token` — SnowLuma OneBot accessToken、`snowluma.dir` — SnowLuma 解压目录
- `astrbot.exe/python/app_dir` — AstrBot 路径
- `llm.api_key` — DeepSeek API Key（战报 LLM 翻译/分析）
- `data.api_watch_enable` — 是否启用 `/api` 每分钟自动巡检，默认开启
- `data.api_watch_interval` — 巡检间隔秒数，最低 60
- `paths.*` — 对照表路径（相对项目根）

插件通过环境变量 `HD2_PROJECT_DIR` 定位项目根（读取 tables/ 对照表）。

## 四、对照表维护

- 变量对照表 `tables/HD2行动变量对照表.md`：分类=`## `，参数=表格行 `|原文|译文|描述|` → 修改后 `/查表` 即时生效（动态读取）
- 星区对照表 `tables/星图对照表_修正版.md`：`|星区|英文|中文|` → 修改后 `/查表 星区` 即时生效
- ⚠️ `planet_info` 插件词库（VARIANT_CN 等）为硬编码，新增词条需同步插件代码

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| WebUI 打不开 / Failed to fetch | 重新运行 `python scripts/hd2_webui.py`；服务被杀可用页面内「重启WebUI」 |
| 机器人没反应 | 状态面板检查 WS 连接；确认平台白名单与群号 |
| QQ 掉线 | 「重启SnowLuma」重新注入 → 在 QQ 窗口重新扫码 |
| 推送指令机器人不回 | 正常：协议端 `reportSelfMessage=false`，自己发的消息不上报；测响应使用「仅测试」（WS 注入） |
| 战报翻译失败 | 检查 `llm.api_key` 是否有效 |

## 六、命令行工具

```powershell
# 推送消息到群（OneBot HTTP；默认群为 config 的 default_group）
python scripts/onebot_send_msg.py <消息文件> [群号]

# 机器人响应测试（WS 注入，伪装群成员，不污染群聊）
python scripts/ws_inject.py "战报"
python scripts/ws_inject.py "查表 孢裂变种"
```
