# HD2 汉化星图网站功能总结

> 站点：https://jerry114514.github.io/HD2-Galatic_war-Map/
> 更新时间：2026-08-21

## 一、站点概况

《绝地潜兵2》（Helldivers 2）实时战况数据面板，托管于 GitHub Pages，纯静态前端 + GitHub Actions 定时抓取数据，零后端依赖。数据每 5 分钟自动更新，浏览器端 60 秒自动刷新。

## 二、板块结构（自上而下）

### 1. 📡 重要指令（Major Order）
- 当前指令简报（中文翻译优先，原文降级）
- 任务目标列表（类型/进度/百分比）
- **实时倒计时**：每秒更新，`deadline + serverTime` 时间校对，颜色分级（<1h 红、<24h 橙、默认白）
- 目标星球卡片展示

### 2. 👥 在线玩家分布
- 四阵营在线人数（超级地球/终结族/机器人/光能族）
- 条形图（阵营色）+ 图例 + 百分比
- 数据源：companion extendedApiInformation

### 3. 🛰️ DSS 民主空间站
- 停靠星球、当前战术行动（飞鹰风暴/轨道封锁/星球轰炸等）
- 行动变量效果中文描述

### 4. 🎯 战术搭配器
- 随机抽取 4 个战备组成配装
- 四维评分进度条（对单/对群/穿甲/第四维）
- 评分评级（S≥44 / A≥32 / B≥20 / C≥10 / D<10）
- S 级金色光晕 + 脉冲动画
- 「换一个」手动微调 + 四维能力轮廓柱状图
- 数据源：tables/stratagems.json（88 个战备）

### 5. 🚨 紧急战情
- **防御战**：双进度条（进攻方阵营色 vs 防守方蓝）+ 时间比值法 + 入侵等级 + 倒计时 + WINNING/LOSING
- **侦察战（RECON）**：成功率大字 + 5 项指标（成功/失败任务每小时、敌人/小时、阵亡/小时）

### 6. ⚔️ 当前可攻打星球
- 解放战星球卡片（单血条 + 解放度）
- 行动变量词条（点击展开中文描述）+ 抵抗度 + 玩家数

### 7. 🔭 民主前瞻
- 待定星系（TBD）独立板块，显示「部分星球已被观测，等待确认民主情况」

### 8. 🌌 星区 / 星球目录
- 按星区分组，中文/英文名对照
- 每颗星球可点击展开详情卡（战略分析/行动变量/兴趣点）

## 三、数据源与抓取架构

| 数据源 | 端点 | 用途 |
|---|---|---|
| 官方 API | api.live.prod.thehelldiversgame.com | 星球状态/战役/新闻/MO（主源） |
| Companion | helldiverscompanion.com | 玩家数/抵抗度/行动变量/MO简报（社区源） |
| helldivers2.dev | api.helldivers2.dev | maxHealth/星区/战役/侦察战统计/MO deadline |
| extended | cdn.helldiverscompanion.com | 分阵营玩家分布 |

**优先级**：官方主源 → companion 补数据 → hd2dev 补静态值，三级回退。

## 四、数据表（tables/）

| 文件 | 内容 |
|---|---|
| starmap.json | 278 星球中英对照 + 星区（Page 本地维护权威源） |
| hd2_variables.json | 行动变量对照表（中文名+描述+effect_ids 关联） |
| effect_id_cn.json | 效果 ID → 中文名（100+ 条） |
| galactic_effects.json | 效果英文名+描述（降级用） |
| stratagems.json | 战备数据（88 个，四维评分+加权） |
| dss_effects.json | DSS 效果 |
| 星图对照表/行动变量对照表.md | 源表（用户维护） |

## 五、自动化与运维

- **fetch-data.yml**：每 5 分钟抓取（多 cron 错峰）+ repository_dispatch 即时触发
- **sync-tables.yml**：每日同步对照表（翻译表已解耦，Page 本地权威）
- **翻译管道**：HD2Web-Trans 仓库，百度翻译 + 术语表，每 5 分钟翻译、每 6 分钟推送到 Page
- **CDN 缓存绕过**：data.json 加 5 分钟粒度时间戳参数

## 六、关键特性

1. 行动变量词条：点击展开中文描述，同名词条合并去重，作战限制红色负面提示
2. 效果翻译：从 hd2dev/companion 抓取，百度翻译 + 术语表（Gloom=阴霾/Terminid=终结族等）
3. 战役判定：campaignType 统一（liberation/defense/recon），侦察战识别（type=1 + event=null）
4. 防御战时间比值法：进攻=已消耗时间/总时间，防守=剩余时间/总时间
5. maxHealth 缓存入库：hd2dev 失败时兜底，避免满血 bug
6. 深色太空主题 + 毛玻璃效果 + 阵营色系统 + 响应式适配
