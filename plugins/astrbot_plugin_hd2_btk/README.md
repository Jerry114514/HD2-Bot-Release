# `/btk` 使用说明

单次伤害对比：

```text
/btk AR-23 武斗虫 头部
/btk AR-23 | 武斗虫 | 头部
/btk AR-23 武斗虫 头部 距离=20 角度=1 破片=3 波及=主体
/btk DOT-FIRE 强袭虫
```

卡阈值扫描：

```text
/btk 卡阈值 AR-23
/btk 卡阈值 AR-23 全部
```

查询资料：

```text
/btk 武器
/btk 武器 突击步枪
/btk 敌人
/btk 敌人 终结族
/btk 敌人 武斗虫
```

多状态敌人（移动工厂）：

```text
/btk E/AT-12 移动工厂 主体          # 同时对比 护甲完好 / 护甲全破 两种状态
/btk E/AT-12 移动工厂·完好 主体      # 只算护甲完好
/btk E/AT-12 移动工厂·护甲已破坏 主体  # 只算护甲全破（也可写 移动工厂破损 / 移动工厂破坏）
```

伤害对比与卡阈值扫描输出战术 HUD 图片卡；帮助和资料菜单保持文字。
结果来自压缩包内原始 `hd2-btk-sdk v0.14.1`，内置 149 件武器与 118 种敌人数据。
裸敌人名默认使用低难记录；高难请写 `武斗虫（高难）`。DoT 武器无需部位。
默认距离为 0 米、正面命中；角度也可填写 0–3。
