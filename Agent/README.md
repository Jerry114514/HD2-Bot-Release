# Agent 工作记录

> 🤖 本项目全程基于 **DeepSeek V4-Flash 的 Agent 能力**生成。
> 本文件夹是 Agent 在开发本项目的过程中形成的工作报告、记忆记录与可复用技能（均已脱敏，不含任何 QQ 号/群号/token/API Key/本机路径）。

你可以直接使用本文件夹中的内容，在自己的本地环境运行、部署或二次修改本项目。

## 内容

| 文件 | 说明 |
| --- | --- |
| [工作报告.md](工作报告.md) | 开发全过程报告：架构决策、关键实现、踩坑记录、功能演进 |
| [记忆记录.md](记忆记录.md) | Agent 的每日工作记忆（开发日志），按日期归档 |
| [skills/](skills/) | Agent 沉淀的可复用技能（上线流程、插件开发规范） |

## 使用方式

- 想了解本项目怎么搭起来的 → 读 `工作报告.md`
- 想复现某个功能的实现细节/踩坑 → 读 `记忆记录.md` 对应日期
- 想维护/扩展机器人（上线、插件开发）→ 参考 `skills/` 下的技能
