## 二、上线稳定化（功能迭代）

### 2.1 缓存体系（3 类）
| 缓存 | 文件 | 逻辑 |
|---|---|---|
| 重要指令 MO | `mo_cache.json` | 最近 5 条新闻无 `NEW MAJOR ORDER` 时直接复用缓存文本；有新 NMO 实时抓取并写回 |
| DSS 资讯 | `dss_news_cache.json` | 涉及 DSS 的最新 1 条资讯，LLM 翻译存双语；DSS 离线/移动时输出中文译文 |
| 新闻 | `news_cache.json` | LLM 翻译按新闻 id 缓存，id 不变输出固定文案 |

统一存放于 `plugins/astrbot_plugin_hd2_war_report/cache/`（独立目录）。

### 2.2 重要指令任务进度
- 解析官方 `Assignment` 的 `progress` 数组 ↔ `tasks` 一一对应，目标量取 `valueTypes==3`

- 任务类型映射：1=解放星球 2=采集样本 3=消灭敌人 9=完成行动

### 2.4 公共库重构（消除重复代码）

## 五、经验沉淀

1. **发布仓库与运行仓库分离**：本地版含真实配置，发布版只含模板——同步脚本按白名单跳过敏感文件
2. **环境变量缺失是发布者第一大坑**：所有路径必须有多层兜底（环境变量 → 项目根 → 插件目录）
3. **AI 生成项目开源**：免责声明（非官方/版权归属/联系方式）+ Agent 记录脱敏是标配
4. **GitHub MCP 网关不可用时的降级路径**：本机直连 API + PAT 完全可以替代
