# 行动变量参数抓取指南（Helldivers Companion 前端 JS）

> 本文档记录如何从 helldiverscompanion.com 抓取行动变量参数（变种/DSS/环境/Cosmic Horror 等），
> 供维护 `HD2行动变量对照表.md` 与插件词库使用。步骤均由 Agent 实际执行验证。

## 原理

行动变量的**完整定义**（实体 slug、分类 niche、文本描述）不在公开 API 中，而是编译进
前端 JavaScript bundle（SvelteKit 构建）。星球页面渲染时根据 `planet.hasID(实体ID)` 决定显示哪些参数。
因此抓取思路：
1. 拿到前端主 bundle（约 5MB）
2. 从中提取实体 ID 表、分类逻辑、描述文本
3. 用星球页面（Playwright 渲染）验证实际出现的参数

## 第一步：定位 JS bundle

主页是 SPA，脚本动态加载。用 Playwright 打开主页后读取资源加载列表：

```python
import asyncio
from playwright.async_api import async_playwright

async def main():
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=True)
        page = await browser.new_page()
        await page.goto("https://helldiverscompanion.com/", wait_until="networkidle", timeout=90000)
        await page.wait_for_timeout(2000)
        resources = await page.evaluate(
            "() => performance.getEntriesByType('resource').map(r => r.name).filter(n => n.includes('.js'))"
        )
        for r in resources:
            print(r)
        await browser.close()

asyncio.run(main())
```

关键产物（2026-08 实测）：
- 主 bundle：`https://helldiverscompanion.com/_app/immutable/chunks/DkIDdJgB.js`（5.18MB，文件名哈希随版本变化）
- 其他：`entry/start.*.js`、`entry/app.*.js`、`nodes/*.js`

## 第二步：下载 bundle

```python
import urllib.request
url = "https://helldiverscompanion.com/_app/immutable/chunks/DkIDdJgB.js"
req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
js = urllib.request.urlopen(req, timeout=120).read().decode("utf-8", "ignore")
open("DkIDdJgB.js", "w", encoding="utf-8").write(js)  # 5.18MB
```

## 第三步：提取实体 ID 表（pawn_*）

## 第四步：提取分类逻辑（niche 分配）

`Ss()` 函数决定实体归属分类：

```javascript
// 实体生成器（JS 片段）
slug: `pawn_${Y0(e.title)}`,          // slug 由 title 生成
niche: e.niche ?? (t == Terminids ? (r ? "EXOTIC LIFEFORM" : "TERMINID BROOD")
    : t == Automatons ? (r ? "SPECIAL UNIT" : "AUTOMATON ASSEMBLAGE")
    : t == Illuminate ? (r ? "COSMIC HORROR" : "ILLUMINATE SECT")
    : "SPECIALIZED UNIT"),
```

结论：**光能族 exceptional 实体 → COSMIC HORROR（深域惧像）；普通 → ILLUMINATE SECT（光能族宗派）**。

## 第五步：关键词上下文提取（描述文本）

实体描述（textTag/override 文本）用关键词搜索上下文：

```python
for kw in ["Polyvoid", "isPolyvoid", "Exostorm", "GreatHost", "Meridian Singularity", "wormhole"]:
    for m in re.finditer(re.escape(kw), js):
        print(js[max(0, m.start()-200):m.start()+400])  # 打印上下文
```

**关键发现（实测）：**
- `isPolyvoid()` = `hasID(pawn_IllPolyvoid)`；Polyvoid 文本：
  「Gravitational wave intensity within [星系] has made travel to the system unsustainable. No probe broadcast has been able to make contact. [星球] has gone dark.」→ 寂域终极形态（引力波封锁）
- Exostorm 3 级与 Polyvoid **互斥**：`isExostormed && !hasID(Polyvoid)`
- The Great Host：niche=`ILLUMINATE FLEET`，Strategic 类型，显示在星系地图
- Meridian Singularity：niche=`MAJOR POINT OF IMPLOSION`，「The Illuminate are moving the singularity toward Super Earth. Anything caught in its path will be torn apart.」
- 默里迪亚黑洞实为虫洞（wormhole），光能族借此进入银河系，伴随 Dark Energy 消失

## 局限与注意

- JS bundle 文件名带哈希，版本更新后需重新定位（第一步）
- 部分实体（如 Spearhead）`textTag` 为空，无独立文本（仅存在于游戏文件与参数中）
- 实体描述可能是模板拼接（`${}` 插值），需结合上下文理解完整含义
- 星球页面抓取受渲染速度限制，全量 272 星球不现实，按「战役 + 光能族」子集即可覆盖绝大多数活跃参数
