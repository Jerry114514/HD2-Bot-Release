# 部署指南（从零到上线）

> 🤖 **AI 生成声明**：本项目全程基于 **DeepSeek V4-Flash 的 Agent 能力**生成。项目根目录的 `Agent/` 文件夹包含 Agent 工作过程中的报告与记忆记录（已脱敏），可参考其在本地运行/部署/修改本项目。

本指南面向二次部署者：在**自己的电脑**上把 HD2 Bot 跑起来。

## 0. 前置要求

| 组件 | 说明 | 获取 |
| --- | --- | --- |
| Windows 10/11 x64 | 必须（NapCat/QQNT 仅 Windows） | — |
| AstrBot 桌面版 v4.x | QQ 机器人框架 | 官方 release（GitHub 下载慢可用 ghproxy 镜像） |
| NapCat v4.18+ | OneBot v11 实现（QQNT 注入） | 官方 release |
| QQNT 9.9.x | 新版 QQ 客户端（NapCat 注入目标） | 官方安装 |
| Python 3.11+ | 运行 Web 控制台等脚本（AstrBot 自带 python 亦可） | — |
| DeepSeek API Key | 战报 LLM 翻译/分析（可选，可用其他 OpenAI 兼容 API） | platform.deepseek.com |

## 1. 安装 AstrBot

1. 下载安装 AstrBot 桌面版（`D:\AstrBot` 或任意路径）
2. 启动后访问 WebUI `http://127.0.0.1:6185`，完成初始化
3. 在 WebUI 配置 LLM Provider（DeepSeek 等），记下 `default_provider_id`

## 2. 安装 NapCat + QQ

1. 解压 NapCat 到任意目录（如 `C:\NapCat\napcat`）
2. 安装 QQNT 9.9.x
3. 用 NapCat 的注入启动方式拉起 QQ（设置环境变量 + NapCatWinBootMain.exe），扫码登录你的机器人 QQ 号
4. 配置 OneBot v11 反向 WS 客户端指向 AstrBot：
   - `websocketClients[0].url = ws://127.0.0.1:6199/ws`
   - `reportSelfMessage = false`（重要：否则机器人自己发的消息会形成循环/干扰）
5. 记下 NapCat WebUI 的 token（`napcat\config\webui.json`）

## 3. 配置项目

```bash
git clone <repo-url> hd2-bot
cd hd2-bot
copy config.example.json config.json
```

编辑 `config.json`，逐项填写（必填项标注 ★）：

```jsonc
{
  "bot": {
    "self_id": "123456789",          // ★ 机器人 QQ 号（NapCat 登录号）
    "groups": [100000001],           // ★ 允许的群号（白名单）
    "default_group": 100000001       // ★ 推送默认目标群
  },
  "napcat": {
    "webui_url": "http://127.0.0.1:6099",
    "token": "你的napcat-token",      // ★
    "dir": "C:/NapCat/napcat",        // ★ NapCat 目录（一键启动用）
    "qq_exe": "C:/Program Files/Tencent/QQNT/QQ.exe"
  },
  "astrbot": {
    "exe": "D:/AstrBot/astrbot-desktop-tauri.exe",  // ★
    "python": "D:/AstrBot/backend/python/python.exe",
    "app_dir": "D:/AstrBot/backend/app"
  },
  "llm": {
    "api_key": "sk-你的key",          // ★ DeepSeek API Key
    "api_url": "https://api.deepseek.com/v1/chat/completions"
  }
}
```

## 4. 部署插件到 AstrBot

```powershell
# 把 plugins/ 下 6 个插件复制到 AstrBot 数据目录
$dst = "$env:USERPROFILE\.astrbot\data\plugins"
Copy-Item plugins\astrbot_plugin_hd2_* -Destination $dst -Recurse
# 重启 AstrBot（杀 tauri + launch_backend 进程后重新启动）
Stop-Process -Name "astrbot-desktop-tauri" -Force
Get-CimInstance Win32_Process -Filter "Name='python.exe'" | Where-Object { $_.CommandLine -match 'launch_backend' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
Start-Process "D:\AstrBot\astrbot-desktop-tauri.exe"
```

验证：`C:\Users\<你>\.astrbot\logs\backend.log` 出现 `Loading plugin astrbot_plugin_hd2_*` 即成功。

### 设置环境变量（插件读取对照表需要）

插件通过 `HD2_PROJECT_DIR` 环境变量定位项目根（读取 tables/ 对照表）：

```powershell
# 系统环境变量（永久）
setx HD2_PROJECT_DIR "C:\path\to\hd2-bot"
# 或每次运行前
set HD2_PROJECT_DIR=C:\path\to\hd2-bot
```

## 5. 配置 AstrBot 白名单与唤醒

1. 平台级白名单（按平台实例区分）：
   `C:\Users\<你>\.astrbot\data\platform_whitelist.json`
   ```json
   {
     "default": ["群A"],
     "napcat": ["群A", "群B"]
   }
   ```
   （平台 id 以 AstrBot 平台配置中的 id 为准）
2. 唤醒：`cmd_config.json` 中 `wake_prefix` 留空（仅 @ 唤醒），或在 WebUI 配置
3. （可选）在 WebUI 配置人格：把 `persona/super-earth-persona.md` 内容填入人格设定

## 6. 启动 Web 控制台

```powershell
set HD2_PROJECT_DIR=C:\path\to\hd2-bot
python scripts\hd2_webui.py
```

浏览器打开 `http://127.0.0.1:8630`：
1. 「🔍 状态」确认 AstrBot/NapCat/WS 连接
2. 「🚀 一键启动」自动拉起 AstrBot + NapCat + 弹二维码（若 QQ 未登录）
3. 扫码登录后即上线

## 7. 群内验证

- `/战报` — 战况速报
- `/查表` — 分类列表
- `/dss` — DSS 状态
- `/战役` — 战役列表
- `/分析` — LLM 战局分析
- `/查询 某个星球名` — 星球信息

## 8. 常见问题

| 现象 | 处理 |
| --- | --- |
| WS 连接不上 | 检查 NapCat websocketClients 的 url/token 与 AstrBot `ws_reverse_port` 是否一致（默认 6199） |
| 扫码报「账号已登录」 | 先退出该 QQ 号的 PC 客户端 |
| 插件读不到对照表 | 确认 `HD2_PROJECT_DIR` 环境变量指向项目根 |
| `/战报` 无新闻/翻译失败 | 检查 `llm.api_key`；网络受限时走代理/镜像 |
| 机器人不响应群消息 | 检查平台白名单（platform_whitelist.json）+ 群号是否正确 |
| 战报里星球名是英文 | 未收录中文的星球保持英文，属正常（可在 tables/星图对照表_修正版.md 补充） |

## 9. 目录速查

- AstrBot 配置：`C:\Users\<你>\.astrbot\data\`（cmd_config.json、platform_whitelist.json、插件）
- AstrBot 日志：`C:\Users\<你>\.astrbot\logs\backend.log`
- NapCat 配置：`<napcat>\config\onebot11_<QQ>.json`、`webui.json`
- 二维码：`<napcat>\cache\qrcode.png`
