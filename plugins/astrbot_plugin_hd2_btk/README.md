# `/btk` 使用说明

单次伤害对比：

```text
/btk AR-23 武斗虫 头部
/btk AR-23 | 武斗虫 | 头部
/btk AR-23 武斗虫 头部 距离=20 角度=1 破片=3 波及=主体
/btk DOT-FIRE 强袭虫
```

卡阈值扫描：

```text
/btk 卡阈值 AR-23
/btk 卡阈值 AR-23 全部
```

查询资料：

```text
/btk 武器
/btk 武器 突击步枪
/btk 敌人
/btk 敌人 终结族
/btk 敌人 武斗虫
```

伤害对比与卡阈值扫描输出战术 HUD 图片卡；帮助和资料菜单保持文字。
结果来自压缩包内原始 `hd2-btk-sdk v0.12.2`，内置 144 件武器与 107 种敌人数据。
裸敌人名默认使用低难记录；高难请写 `武斗虫（高难）`。DoT 武器无需部位。
默认距离为 0 米、正面命中；角度也可填写 0–3。
