# HD2 真理部战况机器人 — 功能详解

> 本文档详解每个功能的**实现细节**（数据源、逻辑、缓存、容错），不含部署/配置说明（见主 README）。
> 开发基准：`HD2-Bot` ｜ 本地运行：`HD2-Bot-Release` ｜ 发布备份：`D:\HD2-Bot-Release-Respo`

基于 **AstrBot + NapCat + Onebot v11** 的《绝地潜兵 2》战况 QQ 群机器人。自动抓取银河战争实时数据，提供战报、DSS 状态、战役简报、战线列表、LLM 战局分析、行动变量/星区查询、随机战备等功能，全中文界面，支持中英文查询。

---

## 二、功能详解（描述 + 实现）

### 2.1 战况速报 `/战报`

**描述**：一次输出四段信息——重要指令（含任务进度）、目标星球战况、战区玩家分布、最新新闻。

**实现**（`hd2_war_report.main._build_report`）：
1. **简报翻译**：先抓官方 `Assignment` 接口的 `overrideBrief` 原文，走 AstrBot LLM（deepseek）翻译（本地修正表 + 术语表兜底）
2. **重要指令**：`_get_major_order` 抓官方 `/api/v2/Assignment/War/801`（失败回退 companion `majorOrders`）
   - **任务进度**：解析 `progress` 数组 ↔ `tasks` 一一对应，目标量取 `valueTypes==3`，显示每项中文任务名 + 百分比 + 当前/目标（`_fmt_big_num` 格式化大数）
   - **目标星球战况**：`valueTypes==12` 提取星球索引，逐星显示解放/防御状态
   - **跃迁封锁提示**：官方 `WarInfo.waypoints` 计算双向封锁边，MO 目标被封锁时附加提示
3. **MO 缓存**：`mo_cache.json`——最近 5 条新闻无 `NEW MAJOR ORDER` 时直接复用缓存文本（避免重复翻译/防 API 波动），有新 NMO 时实时抓取并写回
4. **战区分布**：`_get_warzone_distribution` 抓官方 `Stats` 接口，四阵营玩家占比 + 更新时间
5. **最新资讯**：companion 新闻优先，官方 NewsFeed 兜底；LLM 翻译按新闻 id 缓存（`news_cache.json`，id 不变则输出固定文案）

### 2.2 战线列表 `/战线`

**描述**：列出当前全部战线：星球（中文名 + 星区）｜敌方阵营｜解放战/防御战｜解放百分比/HP，末尾附跃迁航道封锁列表。

**实现**：
- 官方 `Status` 接口 `campaigns`（进攻战）与 `planetEvents`（防御战）合并
- 解放百分比 = `(1 - health / maxHealth) × 100`（进攻战）或 `(1 - event.health / event.maxHealth)`（防御战，含截止时间 UTC+8）
- 星球中文名查 `PLANET_NAME_CN`（271 条），星区查本地星图表 `星图对照表_修正版.md`（官方 sector 为数字/Unknown 不可靠）
- 跃迁封锁：`WarInfo.waypoints` 双向边计算，列出被封锁星球与封锁方向

### 2.3 战役简报 `/战役`

**描述**：当前 Campaign（episodes 最新进行中）的史诗简报：标题 + 阶段任务描述 + 奖励。

**实现**：
- companion live API `episodes` 数组，取最新 `status==0`（进行中）的 campaign
- `phases[].introMessage` 为阶段简报原文，走 LLM 翻译（战役专用提示词 + 术语表）
- 星球名/阵营全中文（`_campaign_race_cn` 映射种族）

### 2.4 DSS 状态 `/dss`

**描述**：DSS 民主空间站——当前停靠星球、生效战术效果（中文 + 完整描述）、下一轮投票倒计时；DSS 离线/移动时输出 LLM 翻译的最新 DSS 资讯。

**实现**：
- **主源官方**：`Status.spaceStations[0]` → 停靠星球 + `activeEffectIds` 效果列表
  - 效果中文：对照表 `TACTICAL ACTION [效果ID]` 标注优先 → `dss_effects.json` → `effect_id_cn.json` 三级映射
  - 外骨骼机甲效果（1260/1261/1262/1384/1385）过滤不单独显示（已含于行动支持描述）
- **备选社区**：官方失败时回退 companion `spaceStations` + `tacticalActions`
- **资讯缓存**：每次查询后台抓 companion 新闻，过滤 DSS 关键词（`dss/space station/convocation bay`），**只保留最新 1 条**，走 LLM 翻译存 `dss_news_cache.json`（双语）；离线时 `_dss_news_supplement` 输出中文译文

### 2.5 战局分析 `/分析`

**描述**：LLM 战略评估：威胁概述 / 关键目标 / 行动建议 / 风险提示（真理部宣传风格，解放度越高优先级越高）。

**实现**：
- 汇总当前战役/战线/DSS/战区分布数据 → 拼装提示词（含术语表）→ AstrBot LLM 生成
- 失败返回错误提示，不阻断其他功能

### 2.6 查表 `/查表`

**描述**：查询行动变量对照表（12 分类 / 参数详情 / 分类子条目）与星区列表 / 星区星球，中英文均可。

**实现**（`hd2_lookup`）：
- 解析用户维护的 `HD2行动变量对照表.md`（Markdown 表格，`[ID]` 标注）与 `星图对照表_修正版.md`
- 支持按分类、按关键词、按星球名（中/英）模糊匹配

### 2.7 星球信息 @机器人 + 星球名

**描述**：星球详情：占领方、抵抗度、防御战 HP/失守进度、行动变量词条（部队/环境/特殊变种）、跃迁封锁、MO 目标标记。

**实现**（`hd2_planet_info`）：
- 中文名 → 英文 slug 匹配（对照表优先，纯英文名直转）
- **官方优先**：`planetActiveEffects` 实时行动变量 + 效果 ID → 中文映射
- **社区备选**：companion 星球页面（Playwright 渲染）解析抵抗度等
- 星球基础数据：helldivers2.dev `api/v1/planets`（浏览器可直连，支持 zh-Hans）

### 2.8 变种查询 @机器人 + 变种名

**描述**：扫描战役星球行动变量，输出所有存在该变种的星球（毫秒级）。

**实现**（`hd2_variant_query`）：
- 官方 `Status.planetActiveEffects` 识别变种（替代早期 Playwright 全页面扫描）
- 变种词库 `VARIANT_CN`（孢裂变种/掠食变种/炽灼部队等）→ 效果 ID 匹配
- 结果带缓存（`_scan_cache`，避免每次重复抓取）

### 2.9 随机战备 `/roll`

**描述**：从全类型战备池随机抽取 4 个；同类型超过 2 个附带毒舌评价。

**实现**（`hd2_roll`）：内置战备池（进攻/防御/支援/辅助分类），随机采样 + 类型统计评价。

### 2.10 指令守卫（自动）

**描述**：拦截所有非 `/` 开头的群消息，关闭 LLM 闲聊，只响应 `/` 指令；用户自己发的指令不响应（self 过滤）。

**实现**（`hd2_guard`，25 行）：事件过滤器，非指令消息直接 `event.stop_event()`。

### 2.11 执行监控（自动）

**描述**：记录每条指令的匹配/执行/耗时/分组，写入 `指令日志.jsonl`，Web 控制台展示。

**实现**（`hd2_monitor`）：提供 `hd2_log()` 埋点，其余 5 个插件 import 调用（monitor 缺失时 no-op 兜底，不影响主流程）。

### 2.12 Web 控制台（8630）

**描述**：浏览器管理面板：一键启动部署、扫码登录、一键群发（战报/战役/DSS/分析）、指定群推送、机器人响应测试（WS 注入）、自重启。

**实现**（`scripts/hd2_webui.py`）：本地 Web 服务，调用 NapCat WebUI API（6099，token 鉴权）完成登录/推送。

## 三、架构与数据流

```
┌─────────┐   OneBot v11 (WS)   ┌──────────┐
│  NapCat │ ◄─────────────────► │  AstrBot │  ← 7 个 HD2 插件（含公共库）
│ (QQ 接入)│    ws://:6199/ws    │ (框架)   │
└─────────┘                     └────┬─────┘
                                     │ 数据抓取（官方优先，社区兜底）
                          ┌──────────▼──────────┐
                          │ 官方 API（主源）     │ ← MO/战役/战线/DSS/新闻/解放%
                          │ api.live.prod.       │
                          │   thehelldiversgame.com│
                          ├─────────────────────┤
                          │ Helldivers Companion│ ← 备用（官方故障时）
                          │ + helldivers2.dev   │ ← 星球名映射
                          └─────────────────────┘
```

**插件分工**：

| 插件 | 行数 | 职责 |
|---|---|---|
| `hd2_common` | 454 | **公共库**：共享常量/HTTP 抓取/表加载/译名表（PLANET_NAME_CN 271 / SECTOR_CN 24），3 插件 import |
| `hd2_war_report` | 1417 | 战报 / 战线 / 战役 / DSS / 分析 / 新闻（最大单体） |
| `hd2_planet_info` | 901 | 星球详情 |
| `hd2_variant_query` | 309 | 变种扫描 |
| `hd2_lookup` | 308 | 查表 |
| `hd2_roll` | 201 | 随机战备 |
| `hd2_guard` | 25 | 指令守卫 |
| `hd2_monitor` | 107 | 执行监控 |

**数据源分层**（官方优先，社区兜底）：
1. **官方 API 主源**：`api.live.prod.thehelldiversgame.com`（2026-08 从游戏流量抓包发现，公开可访问，仅需 `X-Super-Client` 头）——MO/战役/战线/DSS/新闻/解放%/跃迁航道
2. **社区备选**：官方故障（如 500）自动回退 Helldivers Companion 聚合端点
3. **星球名**：helldivers2.dev（支持 zh-Hans）+ 本地对照表中文译名
4. **LLM**：AstrBot 接入的 deepseek（翻译/分析），失败有本地修正表/原文兜底

**缓存体系**（`hd2_war_report/cache/`）：
- `mo_cache.json`：重要指令——最近 5 条新闻无 NMO 时复用
- `dss_news_cache.json`：DSS 资讯——LLM 翻译双语，离线补充
- `news_cache.json`：新闻——LLM 翻译按 id 固定复用
- 公共库表加载 3 层兜底：`HD2_PROJECT_DIR` → 项目根 tables → 插件目录副本（发布者无环境变量也能跑）
