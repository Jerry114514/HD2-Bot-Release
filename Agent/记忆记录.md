## 2026-08-09

### 上下文污染导致机器人输出旧固定文案（重要坑）
- 现象：机器人一直回复旧的固定文案，无论怎么改人格提示词/清缓存/删除重建人格都没用
- 根因：旧版人格回复过的固定文案存进了群聊会话历史（conversations 表），LLM 每次对话带全部历史，看到「提问→固定文案」模式就一直模仿输出
- 排查：改 persona 无效 → 搜日志命中 → 解析 content JSON 数组（中文可能转义，需 json.loads）才找到
- 解决：停 AstrBot → 清空该会话 content → 重启
- 教训：AstrBot 会话历史是 LLM 上下文的一部分，改人格后仍出现旧回复先查会话历史！

### 人格更新
- 删除重建 2 个 persona（均为无限制版）
- 人格更新流程：备份 → 停 AstrBot → 改 DB → wal_checkpoint(TRUNCATE) → 重启

### 定时推送任务教训
- cron 定时推送不能用 systemEvent 注入主会话（事件只记录不执行）→ 必须用 agentTurn（isolated）+ 明确 prompt + timeoutSeconds
- 实测：agentTurn 超时重试后成功；systemEvent 完全没发

### 推送脚本
- NapCat WebUI API：登录 `/api/auth/login`（sha256(token+".napcat") → Credential）→ POST `/api/Debug/call/debug-primary`（body: {"action":"send_group_msg","params":{...}}）
